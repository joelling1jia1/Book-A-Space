# Book A Space – deploy
1. Sheet → Extensions → Apps Script → paste apps-script/Code.gs → Deploy → Web app (Execute as: Me, Access: Anyone) → copy the URL.
2. public/index.html: replace PASTE_APPS_SCRIPT_WEB_APP_URL with that URL.
3. Add space photos to public/img/ named main.jpg, multi.jpg, study.jpg, hangout.jpg, kids.jpg, toddler.jpg.
4. Push to GitHub, Netlify publish directory = public. Open over https, then Add to Home Screen.
